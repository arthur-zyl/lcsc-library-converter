LCSC Library Converter

Download LCSC and EasyEDA Pro resources and convert them to KiCad, Cadence or Altium libraries.

Run LCSC-Library-Converter.exe. The interface follows the system language: Chinese for Chinese systems; English otherwise.
The app includes its EasyEDA Pro extension and Altium conversion dependencies.
Use the first-run guide to configure FreeCAD Python and any required KiCad/Cadence installation.
Altium conversion requires FreeCAD Python 3.11. No Node.js installation is needed.
Extract the complete portable ZIP before running the EXE.
Personal settings and login data remain in %APPDATA%\eda-component-hub.
The project is independent; component resources originate from LCSC and EasyEDA Pro.
See resources/app/LICENSE and THIRD_PARTY.md for source and license information.

--- Chinese instructions ---

LCSC Library Converter

元件及原始符号、封装、3D 模型来源于立创商城与立创 EDA。
本工具为独立开发的下载、提取和多 EDA 库转换工具。

1. 运行 LCSC-Library-Converter.exe，首次启动按引导配置工具。
2. 安装 FreeCAD，并选择其 bin 文件夹中的 python.exe。
   AD 转换依赖针对 Python 3.11 构建；请选择匹配版本的 FreeCAD Python。
3. KiCad 导出需配置 KiCad 9 或更新版；Cadence 导出需配置 Capture/Allegro。
4. 登录立创 EDA，在软件中复制插件文件夹路径，导入该文件夹中的 .eext 插件，
   开启外部交互权限。之后插件会自动连接。
5. 在立创商城点击“加入清单”，选择目标 EDA 后批量导出。

免安装 ZIP 必须完整解压后运行，不要单独复制 EXE。
配置、清单及日志保存于当前用户的 AppData\Roaming\eda-component-hub\data。
登录状态保存在同一用户数据目录；安装目录不保存个人导出数据。
卸载不会删除这些个人数据。导出的库保存在设置中的目标目录。

原始库、模型及附带第三方依赖的权利归其各自权利人所有。
Electron 与第三方依赖的许可证文件保留在分发目录中。
